# Análisis de Genomas Bacterianos
Repositorio con comandos para el análisis de genomas bacterianos. 

## Contenido

-Ensamlaje genómico: Nanopore.
-Anális de genes de resistencia antimicrobiana.
-Identificación de elementos genético móviles: búsqueda y análisis de la ubicación de los genes de resistencia en plásmidos, trasnposones, integrones, bacteriófagos, elementos de inserción.
-Identificación de genes de virulencia.
